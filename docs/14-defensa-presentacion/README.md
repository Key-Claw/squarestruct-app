## Enfoque De Defensa

SquareStruct debe presentarse como un proyecto full stack academico de DAW1:

- problema y objetivo;
- arquitectura simple y clara;
- frontend React;
- backend Express;
- base de datos MySQL;
- autenticacion y roles;
- pedidos y administracion;
- disenador 2D/3D con limite documentado;
- tests, Docker, Postman y CI.

## Como Defenderlo

La mejor defensa es explicar decisiones sencillas con seguridad: que se hizo, por que se hizo asi, donde esta en el codigo y que quedaria como mejora futura.
