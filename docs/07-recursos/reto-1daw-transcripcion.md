# Reto 1 DAW - Backend + Frontend

> Transcripcion resumida del documento original del reto.
> Revisar siempre el documento fuente si hay dudas sobre requisitos oficiales.

## Objetivo general

Desarrollar una aplicacion web completa que incluya backend, frontend, base de datos relacional, documentacion, pruebas y despliegue o preparacion de entorno.

## Requisitos principales

- Backend funcional con API REST.
- Conexion a base de datos relacional.
- Frontend funcional que consuma la API.
- Operaciones basicas: registro, login, catalogo, pedidos y administracion.
- Dockerizacion de backend y frontend.
- Scripts SQL para crear y poblar la base de datos.
- Documentacion tecnica y de uso.
- Colecciones Postman para probar la API.
- Control de versiones y buenas practicas de organizacion.

## Entregables

- Codigo fuente completo y estructurado.
- README y documentacion tecnica.
- Arquitectura, API, testing y despliegue documentados.
- Scripts SQL: schema, seeds y migraciones si aplica.
- Dockerfile y Docker Compose.
- Pruebas automaticas y manuales documentadas.
- Colecciones Postman.
- Evidencia de uso de Git, ramas y commits claros.

## Criterios de evaluacion

- Cumplimiento de requisitos funcionales.
- Calidad y organizacion del codigo.
- Claridad de la arquitectura.
- Conexion correcta entre frontend, backend y base de datos.
- Calidad de pruebas automaticas y manuales.
- Documentacion clara y defendible.
- Uso correcto de Docker.
- Buenas practicas de seguridad y validacion.
- Presentacion y defensa del proyecto.
